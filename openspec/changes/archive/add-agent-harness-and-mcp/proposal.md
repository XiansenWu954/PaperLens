# add-agent-harness-and-mcp Proposal

Add explicit Agent harnesses and project-level MCP tools so Agent concepts are demonstrable and not decorative.

## Why
- Harness gives a clean place for execution state, tool routing, SSE, logging, errors, and evaluation.
- MCP demonstrates external tool service exposure without turning every internal helper into an MCP tool.

## Scope
- Execution harness, lightweight evaluation harness, demo seed harness, project MCP tools.
