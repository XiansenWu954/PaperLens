# add-workbench-frontend-v2 Proposal

Replace the single research screen with a resume-grade workbench: Dashboard, Project Workspace, Evidence Board, Citation Map, Report Studio, and Agent Chat.

## Why
- The frontend must show a complete Agent application, not a prompt box.
- Chat/tool/RAG events should be visible and understandable.

## Scope
- Vue routes, stores, API types, and workbench panels.
- No auth, billing, or multi-user settings.
