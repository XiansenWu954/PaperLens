# add-workbench-frontend-v2 Design

## Information Architecture
- Dashboard: project list, recent status, demo entry.
- Project Workspace: paper library, evidence/report/graph tabs, right-side chat.
- Evidence Board: project paper list and metadata.
- Report Studio: versions and report content.
- Chat Panel: token stream, tool calls, evidence, and paper additions.

## Visual Direction
Keep the scholarly workspace style: restrained, clear, dense, and low-decoration.
