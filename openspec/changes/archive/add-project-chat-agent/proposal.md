# add-project-chat-agent Proposal

Add a project-scoped Agent Chat that can answer against the current project RAG corpus and autonomously call safe tools to search and add papers.

## Why
- A resume-grade Agent app should demonstrate ongoing user-Agent collaboration, not one-shot generation.
- Chat is where Function Calling, Prompt Engineering, RAG, and tool observability become visible.

## Scope
- Chat sessions/messages, streaming chat endpoint, safe tool execution.
- Agent may add papers but cannot delete papers or overwrite reports.
